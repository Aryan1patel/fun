# 💎 Minecraft Love Story - Interactive Website

An immersive, beautifully animated React website telling the story of Oliver & Ashley's journey together, featuring stunning visual effects and interactive elements.

## ✨ Cool Features Added

### 🎨 Visual Effects
- **Dynamic Starfield Background** - 250+ twinkling stars with individual glow effects
- **Aurora Animations** - Four-layer atmospheric aurora with smooth wave motion
- **Liquid Morphing Blobs** - Organic animated gradient backgrounds
- **Custom Cursor** - Magnetic cursor with ring glow and smooth tracking
- **Floating Particles** - 14 different emoji particles with drift and glow effects

### 🌈 Enhanced Animations
- **Glass Morphism** - Advanced backdrop blur with brightness saturation
- **Neon Pulse Effects** - Glowing text with breathing animations
- **Shimmer Overlays** - Diagonal shimmer on buttons and cards
- **3D Card Tilts** - Perspective transforms on hover
- **Magnetic Buttons** - Spring-loaded button interactions
- **Rainbow Borders** - Animated gradient borders on quiz sections

### 🎭 Mode Switching
- **Oliver Mode** (Boy) - Ice blue theme with dark cosmic background
- **Ashley Mode** (Cute) - Hot pink theme with light pastel background
- Toggle between modes with animated rotation effect

### 🎪 Interactive Elements
- **Smooth Scroll Reveals** - Staggered card animations on scroll
- **Progress Indicators** - Glowing animated progress dots
- **Enhanced Toast Notifications** - Bouncy slide-in notifications
- **Lightbox Gallery** - Full-screen image viewer with blur backdrop
- **Quiz System** - Interactive quiz with progress bar shimmer
- **Copy-to-Clipboard** - One-click copy for IDs and server IPs

### 🚀 Performance Optimizations
- Font smoothing for crisp text
- GPU-accelerated transforms
- Reduced motion support for accessibility
- Efficient particle cleanup
- Smooth 60fps animations

### 🎯 Special Effects
- Holographic text gradients
- Breathing heart animations
- Ripple effects on click
- Glow halos on interactive elements
- Parallax depth layers
- Gradient text animations

## 🛠️ Tech Stack
- React 19 with Hooks
- Vite for ultra-fast development
- Canvas API for starfield
- CSS3 animations & transforms
- Framer Motion ready

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Visit **http://localhost:5173/** to see the magic! ✨

## 🎮 Navigation
- Use the top navigation dots to jump between chapters
- Back button to go to previous chapter
- Toggle mode button (🌙/🌸) to switch themes
- Smooth chapter transitions with block animations

## 💝 Chapters
1. **Title** - Hero introduction with character stats
2. **Story** - Timeline of your relationship
3. **Dates** - Important dates and memories
4. **IDs** - Gaming usernames and contact info
5. **Servers** - Minecraft server details
6. **World** - Long-distance love across continents
7. **Games** - Interactive quiz about your journey
8. **Love Notes** - Sweet messages and note generator
9. **Home** - Final celebration page
